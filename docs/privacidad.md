# Ridmer – Política de privacidad

Última actualización: 11 de noviembre de 2026

Ridmer es una herramienta privada que usa únicamente el dueño del canal de YouTube "Ridmer" para subir y programar
sus propios videos con la API de datos de YouTube (YouTube API Services).

**Qué datos usa:** solo el permiso que el dueño del canal otorga para subir videos, poner títulos, descripciones,
etiquetas y miniaturas en su propio canal, y leer el nombre del canal. No accede a datos de otras personas.

**Dónde se guardan:** el permiso de acceso se guarda solo en el servidor privado del dueño. No se vende, no se comparte
con terceros y no se usa para publicidad.

**Cómo quitar el acceso:** en cualquier momento desde https://myaccount.google.com/permissions

Esta herramienta usa los Servicios de API de YouTube. Al usarla aplican las Condiciones del Servicio de YouTube
(https://www.youtube.com/t/terms) y la Política de Privacidad de Google (https://policies.google.com/privacy).
